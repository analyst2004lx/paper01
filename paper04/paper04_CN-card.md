## 2. 核心主张（可证伪，写成命题）

**C1（缺口存在）**：在同时用工序依赖图刻画加工先后、又用时间窗预约记录走廊占用的柔性作业车间中，存在一类扰动（B 类：走廊阻断、走廊通行变慢），它使原排程在扰动下不可行，而按"受影响工序"划定的重调度范围为空——因而现成划界会把它判为无需重调度。

- 证据：`prop:miss`（`830–845`，含证明）｜`\PassMiss` = 50/50（`tab:e1`）｜`tab:e6` 两类 B 扰动各 50/50 为空、两类 A 扰动各 0/50（`1433–1436`）｜外部批 `\PubPassMiss` = 50/50（`1882`）
- 可证伪方式：给出一个 B 类扰动实例，使 `def:task_impact` 下 \(T_{\mathrm{direct}}\neq\varnothing\)；或给出一个 \(\mathrm{Seeds}\neq\varnothing\) 却仍可行的原排程；或指出 B 类扰动在实践中不存在
- 依赖的约定：`def:task_impact` 对 B 类**约定** \(T_{\mathrm{direct}}=\varnothing\)（`805`）。作者已就地声明该半句是定义的推论、非发现，重量在后半句（`1264–1268`）

**C2（对象成立）**：把重调度范围定义为预约影响集 \(\mathrm{Cl}(\mathrm{Seeds})\) 后，它由四类依赖边唯一确定、对外封闭；在同一套第 1 级改路程序下足以恢复可行；在 A 类扰动上它包含工序依赖图划出的范围。

- 证据：`def:dep`（`878–892`）+ `def:strc`（`894–910`）｜`prop:struct`（`936–947`，含证明）｜`prop:outside`（`987–1001`，含证明与四条前提）｜`\PassClosed` = 50/50、`\PassInvar` = 50/50（`tab:e2`）｜`\FeasRtwo` = 50/50（`tab:e3`）｜A 类包含性 100/100，其中 `\StrictlyLarger` = 87/100 严格、13 格相等（`1442–1445`）
- 可证伪方式：在 \(G_R^\circ\) 上找到一条从集内指向集外的边；或找到某 A 类格使 \(U_{R1}\not\subseteq\mathrm{Cl}\)；或使第 1 级改路（不扩大范围）在某格不可行；或使集外占用的走廊/时段/车辆发生漂移
- 强度限定：`prop:outside` **只是充分条件**（`1907`、`1984`）；闭合性是定义的推论而非独立定理（`949–951`）

**C3（净作用是稳定性）**：预约影响集的净作用是更少改写占用，而不是更快、也不是更短的完工时间。与只差"允许改写哪些占用"的 RA 对照相比，算法耗时与 \(C_{\max}\) 几乎不变，改动比例由 0.604 降到 0.540。

- 证据：`tab:cheap`（`1698–1707`）｜`\RAStabWTL` = 31/18/1、`\RAStabP` = \(8.8\times10^{-7}\)（Wilcoxon 符号秩双侧）｜`\RAStabMean` = 0.064、`\RAStabMed` = 0.029｜`\RACmaxRatio` = 0.999、`\WinVsAllFuture` = 4/46/0｜`\MsCheapRtwo` = 2.74 对 `\MsAllFuture` = 2.76 ms
- 可证伪方式：在同协议下 R2 与 RA 的改动比例差不显著；或两者耗时/\(C_{\max}\) 出现系统性差异（那说明差异不只来自划界）
- 强度限定：幅度随影响集排除得多而变大，**方向一致但不构成比例关系**（B09 已删去原"成正比"的线性主张），在影响集接近平凡上界时趋于消失（`1748–1751`、`1966`）；事后阈值 `\WorthThresh` = 0.93 为样本内分档、不外推（`1758–1759`）

> C1–C3 之外，本文**不把**"有界修复更快"当作独立主张：`1744` 明写毫秒级响应来自单遍改路、不重开搜索，而不是来自影响集。施工时任何一块都不得把速度写成影响集的功劳。
