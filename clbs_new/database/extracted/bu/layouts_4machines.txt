# 附注(与 Lyu 2019 的一处分歧,记录备查):
# Lyu 等 (2019) 在取用这四个布局时写道 "We revised a value in the fourth layout because of
# the irregular transport time (the travel time from M2 to M1 should be 12)"。
# 原文 Table 13 布局 4 的 M2->M1 确为 14(已在 200 dpi 下核对)。以 14 计并不违反三角不等式
# (M2->M3->M1 = 8+8 = 16,M2->M4->M1 = 6+14 = 20,M2->LU->M1 = 20+4 = 24,均不短于 14),
# 故 Lyu 的修改依据不是度量不一致,而应是与其导轨几何的一致性。本文档一律以**原文的 14** 为准;
# 若将来取用 Lyu 的参照值,须注意其算例在这一格上与原文不同。
