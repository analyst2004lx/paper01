## 2. 术语取舍说明

以下词语经核查属本领域规范术语或已在文中明确定义，**予以保留**：

| 保留词 | 理由 |
| --- | --- |
| 沉默 / 可问责沉默 | 对应 accountable silence，首次出现处已补充定义：设备在约定心跳窗口内未披露预像这一可判定事件 |
| 串谋 | 对应 collusion，安全文献标准译法；首次出现处补充"多台被控设备协同伪造互证"的说明 |
| 口径 | 保留但不再单独裸用，按语境展开为"统计口径""最严格预算口径" |
| 看门狗 | watchdog 的标准译法 |
| 档 | 实验分层，正文明确为"四档"并逐档命名 |
| 判别力 | 对应 DR–FAR 的区分能力，已在指标定义处说明 |
| 逾窗 | 已在协议小节定义为"超出互证窗口" |

## 5. 配图工具链修复

重新生成配图过程中暴露并修复了两个与文字无关的问题：

1. **`ValueError: Invalid RGBA argument`** — 本机 Matplotlib 3.1.3 不支持三位十六进制色值。将 5 个中文脚本中的 `#111` 等缩写色值统一展开为六位形式（`#111111`）。
2. **`RuntimeError: TrueType font is missing table`（CJK 字体嵌入）** — 为各脚本加入 `pdf.fonttype: 42`，并在 `fig/_style.py` 中新增 `subset_pdf()`：当输出 PDF 超过 1 MB 时调用 `pdftocairo` 重新嵌入实际用到的字形，避免整份中文字体被写入导致的体积膨胀；`pdftocairo` 不可用时自动跳过。

修复后 5 张中文配图均无 Type 3 字体。英文配图（`fig_*.pdf`，不带 `_CN`）仍为 Type 3，本轮未处理。
