## 0. 筛选口径与评分方法

### 0.1 「非 OA」如何界定

本文件所选期刊全部为 **订阅制或混合制（hybrid）**：作者可以选择订阅模式发表，**不缴任何 APC**；OA 只是可选项（不选即免费）。Elsevier / Taylor & Francis / Springer 的 hybrid 刊均满足；IEEE 期刊默认订阅制，但**超页费**另计（见各篇风险提示）。

**已主动排除的全 OA 刊**（无论分区多高，均不符合硬性条件）：IEEE Access、Sensors、Applied Sciences、Mathematics、Machines、Electronics、Scientific Reports、Journal of Big Data、Complex & Intelligent Systems、Journal of Cloud Computing、EURASIP 系列、MDPI 与 Frontiers 全线、Nature Communications 系列。

**稿件画像**：问题层沿用 van Os 的带无冲突运输约束 FJSP 设定，贡献在求解方法；闭环双层 + memetic；四级基线阶梯、10 算例 × 10 种子 × 同挂钟预算、Holm 校正 + Hodges–Lehmann 区间；主效应 18.86%、端到端 21.35%；另有公开基准（Homayouni & Fontes）退化对标 12/20 逐位命中。方法学纪律极强，统计报告规范。

### ★ 首选推荐：**Computers & Industrial Engineering**（Elsevier）

理由：工业工程 + 计算方法学是该刊主航道，受控算例族 + 严格配对统计的写法正是它的常见体裁；对“自建受控算例 + 公开基准辅助标定”的组合接受度高于纯制造类刊；订阅模式零费用；初审极快（官网 4 天），评审后决定约 90 天。四篇中它对本文的“方法学纪律型”写法最友好，**给小修的概率在同档 Q1 刊中相对最高**。

- **CAIE（91）**：契合 33/35。它常年发表 FJSP、AGV 调度、元启发式 + 统计对照的稿件，本文的“同挂钟预算”“一次只改一个维度”正是审稿人会赞赏的协议设计。风险最低。

### 投稿风险与应对

1. **自建算例族**是最大攻击面（局限 (1) 已自陈）。Cover letter 应主动说明：该支尚无公开基准（通行 FJSP_PT 发布常数矩阵，实测 7/7 布局不对称、2 张连最短路闭包都不是），并强调已在 20 个公开算例上做退化对标、12 个逐位命中文献值。
2. **“派遣机制逐格校正后 0/10 显著”**如实写在正文。建议在 Cover letter 里把它定位为“已按族校正的诚实报告”，而不是等审稿人发现后再解释——这类主动披露在 CAIE/COR 通常换来好感。
3. 若首投 JMS/RCIM 被要求产线验证而无法补，**横向平移到 CAIE**成本最低（同出版社、同体裁、格式改动小）。

## 2. Paper02：时序半马尔可夫 + 参考模型可行性约束的工业离散事件注入攻击检测

**稿件画像**：问题层指认“离散活动事件注入”这一层；机制层为硬层可行性掩码（BPMN 自动导出、良性违反 0）+ 半马尔可夫分布型停留核 + 结构通道，三路并行、共形校准 + CUSUM；理论层给出仅标签阈值族的不可能性与抢跑量上界 ρ*(α,σ)；在 Fischertechnik Trier 真实产线日志上按可复现协议合成 A1–A6 六类注入，与 BUTLA / TABOR / HSMM / 符合度代理同误报预算对照。主表如实写“不全面优于”。

理由：应用安全检测的老牌主刊，ICS/CPS 入侵检测是其固定栏目；它**明确接受“分攻击类型逐格报告、部分类别不占优”**的诚实评估体裁（这与本文的口径完全一致，在追求 SOTA 全面领先的刊上反而是硬伤）；共形预测 + 序贯检验 + 归约式不可能性证明的组合在该刊读者群中有认知基础；订阅模式零费用；官网自报评审后决定约 56 天，是同档 Q1 安全刊中较快的一档。

### 逐条点评

- **COSE（90）**：契合 33/35。唯一顾虑是该刊近年安全检测投稿量巨大，编辑桌拒率不低；但本文有“真实产线日志 + 可复现注入协议 + 不可能性证明”三件硬料，过编辑桌的概率不低。
- **IJCIP（89）**：**若把“稳妥拿下小修”排在“分区尽量高”之前，这是第一选择**。契合度几乎与 COSE 持平（CPPS/ICS 保护是其核心），门槛略低一档 → 小修概率明显更高；初审仅 5 天。缺点是部分年份在个别 JCR 类目上落在 Q2。

### 投稿风险与应对

1. **公开日志无注入标注、攻击为合成**，是必被问的一条。应在 Methods 中前置“可复现注入规则表 + 三种子 + 同误报预算 + 基线按原文结构约束复现”，并明确“BUTLA/TABOR 无官方可接本日志实现，已列保留项与近似项”。
2. **A4/A6 低于仅标签消融**要主动写成“三路均分 α 的预算代价”，并给出图（A4 一行接近全白）。诚实披露在 COSE/IJCIP 是加分；若投 TII 这类偏好“全面领先”的刊，可能被读成方法缺陷。
3. **共形保证只在可交换口径成立**（时序通道时间序经验误报 0.024 > 名义 0.01）这一条必须写在方法节而非局限节，否则审稿人会认为在隐藏。

## 3. Paper03：耦合互证与可问责沉默的被劫持设备任务状态伪造检测

**稿件画像**：问题层为“无物理残差的离散任务状态伪造”，指出单观测者残差/FDI/孪生族结构性失效；机制层为任务图诱导的 O(1) 见证集耦合互证 + 一次签名锚定哈希链的可问责沉默；理论层为串谋界（前向闭包基数，中位 5、最坏 1）与带宽—安全裕度权衡（最严 7.7 KB/s ≈ 5 Hz 全网 PBFT 的 1/131）；附录含原像披露不可否认性的归约证明；Trier 日志 + P1–P4 注入 + 四档基线；见证选取消融（空间邻居仅恢复约 52% 检出）。

### ★ 首选推荐：**Computers & Security**（Elsevier）

理由：本文的对话对象（PeerReview、Polygraph/ABC、TESLA、GOOSE、位置证明）正是该刊长期覆盖的可问责性与协议安全谱系；“带归约证明的安全性命题 + 真实日志实测 + 带宽预算定理”这一混合形态在 COSE 有成熟先例，而在纯密码学刊会嫌实证多、在纯工业刊会嫌证明多。订阅零费用、评审后约 56 天。

- **JNCA（79）**：本文的心跳间隔反解、带宽—安全折中、O(1) 见证集复杂度分析，很对该刊口味。缺点是它对“攻击检测语义”的兴趣弱于对“协议与网络开销”的兴趣，可能要求把安全叙事改成协议叙事。

- **TDSC（72）**：与 TIFS 同理，且更慢。仅在明确以“可问责性理论贡献”重写后考虑。

### 投稿风险与应对

1. **覆盖缺口必须前置**：约 29.95%（917 条）活动无对手方，互证关闭、P3 维持心跳仍可获胜。已在正文写明，Cover letter 需再强调“合用后 P1–P3 无获胜支”**只在 H 上有对手方的交接上成立**，避免被读成过度声称。
2. **攻击提出权归属**：non-triggering misbehavior 的学术提出权属既有文献，本文贡献是运行时检出与归责。这一句必须出现在 Introduction 与 Related Work 两处，否则安全刊审稿人会直接指“新颖性主张不实”。
3. **无 AGV、无通信层的数据限制**：心跳/丢包/危害预算为引用或仿真参数，须逐项标注来源；否则带宽定理会被质疑为自选参数。
4. **W1（PBFT 式共识）检出恰为 0、带宽是本文 131 倍**这一行读数极有说服力，建议提到 Results 开头而非埋在第四档。

## 4. Paper04：任务图覆盖不到的级联损坏——时空预约影响闭包（STRC）

**稿件画像**：问题层指认 B 类扰动（走廊阻断/降速）下任务图边界系统性失效（50/50 空影响域而原排程不可行）；机制层定义时空预约影响闭包，给出结构闭合性与外侧字段不变的充分条件；方法层为闭包上的有界修复（第 1 级改路 + 失败扩域），毫秒级响应；含 E1–E8 八组实验、外部布局复现批次、四类扰动 × 两种划界对象覆盖矩阵。**如实报告负面读数**：C_max 在全部 18 个预算点上劣于热启动全局重解、无交叉点；闭包不最小（覆盖约 92% 活预约）；结构可预测性是负结果。

### ★ 首选推荐：**Computers & Industrial Engineering**（Elsevier）

理由：本文的核心贡献是**概念与划界对象**（影响边界该画在哪张图上），而不是“完工时间更优”。这类贡献在要求 benchmark 全面领先的刊上极易被拒；CAIE 长期接受“问题指认 + 形式化对象 + 同引擎消融”的方法学稿件，且其审稿人熟悉 AOR / match-up / 局部重调度这一支文献，能读懂 R1 对照臂的意义。订阅零费用、初审 4 天。与 Paper01 同刊虽是同一作者组，但**对象与时机截然不同（构建 vs 定位损坏）**，可在 Cover letter 一句说清，不构成切香肠。

### 逐条点评

- **CAIE（90）**：唯一需要预案的是“C_max 全区间劣势”。见下方风险 1。
- **JMS（86）**：动态重调度、扰动响应是该刊常见主题，且周转最快（至录用 122 天）。它对“毫秒级响应 + 产线可执行性”的兴趣高于对 C_max 最优的兴趣，**这一点实际上对本文有利**；顾虑仍是可能要求真实产线验证。
- **COR（80）**：命题 + 闭合性证明 + 最小性讨论会被认真读，注 rem:minimality 的三条理由正是该刊风格。但它可能要求把“最小释放集”做成可求解的优化问题 → 大修风险。
- **JIM（78）**：契合“智能制造中的扰动恢复”，Springer hybrid 订阅免费。审稿速度中等，偏好学习类方法，本文是确定性单遍协调，可能被问“为何不上学习”。
- **TASE（77）**：AGV + 车间自动化 + 形式化命题都对口。缺点是慢、页数限制、超页费；且 IEEE 审稿人常直接追问与精确方法的 optimality gap。
- **IEEE/CAA JAS（70，拔高备选，不计入 3–5 正式推荐）**：非 OA 条件满足（Traditional 投稿零 APC，详见 Paper01 节）。对本篇而言风险高于 Paper01：该刊排名第 1、门槛最高，而本篇**主动写明 C_max 全区间劣于全局重解**，在顶刊审稿人处极易被直接读成“方法未带来性能收益”而拒稿。若确要投，必须先把贡献重述为“扰动影响边界的可计算定义 + 有界修复的稳定性收益”，并把 E7 便宜对照臂提到最前。**不建议作为本篇的首投或次投。**

### 投稿风险与应对

1. **C_max 全区间劣于全局重解、无交叉点**——这是全稿最大风险，也是最容易被误读为“方法无效”的一处。建议：
   - Cover letter 第一段即声明：本文贡献是**划界对象**，响应时间是机制形态的结果，闭包兑现的是稳定性（RA 对照臂：只差释放集，改动比例从 0.604 降到 0.540，逐格 31/18/1，p = 8.8e-7）；
   - Abstract 与 Introduction 各留一句“本文不宣称在完工时间上优于全局搜索”，抢在审稿人之前说；
   - 把 E7（便宜对照臂）提到实验章靠前位置——它已排除“对照选贵了”这一质疑，是防守 C_max 劣势的关键证据。
2. **闭包覆盖约 92% 活预约、不作最小性主张**：注 rem:minimality 已写得很充分，但摘要中也需一句，否则“有界/局部”会被当作过度声称。
3. **与 Paper01 共用下层实现**（路网、时间窗路由、校验器）已在局限中自陈“尚未在第二套独立实现上复现”。若审稿人追问，可承诺提供匿名仓库（稿件已规划审稿期匿名仓库 + 接受后 DOI 登记），这一条对 Elsevier 审稿人通常足够。
4. **外部布局只外部化了拓扑、时间标定仍自建**：这是必被问的第二条。已备好答案（Lyu 附录未发表逐段时长；公开族运输/加工时长比过低会使争用消失），建议直接写进 Methods 而非 Limitations。

## 7. 中文路线：五大学报推荐（与第 1–4 节互斥）

### 7.1 前置约束：与英文路线互斥，每篇只能选一条

第 1–4 节的英文 SCI 推荐与本节的中文推荐**针对同一批稿件，因此互斥**。同一研究成果中英文各发一次，国内期刊与 Elsevier/IEEE 均认定为重复发表，五大学报的投稿声明中普遍有此条款。**每篇论文只能选一条路**。

如果确实想中英文都要，只有两种合规做法：

1. **一篇拆两篇**：例如 Paper01 的闭环双层主体投 SCI，把下界剪枝 + 胜者路径复用这对输出等价加速（含等价性命题与 2.33× 实测）单独扩写成中文稿。前提是拆出的部分有独立贡献量，否则会被判切香肠。
2. **中文先发、英文版实质性扩展**：补新实验或新定理，并在英文稿中显式引用中文前作、在 Cover letter 声明。此路径在国内工科常见，但目标英文刊是否接受需投稿前致信编辑确认，不可自行假定。

### 7.2 「五大学报」范围说明

计算机领域通称的五大学报为：**《计算机学报》《软件学报》《自动化学报》《电子学报》《通信学报》**。「四大学报」指去掉《通信学报》的前四本。《计算机研究与发展》在 CCF 中文科技期刊分级目录中同为 A 类、地位相当，只因刊名不含「学报」而不列入该习称；同类还有《中国科学：信息科学》《电子与信息学报》。

**这五本均为中文刊，收录于 EI / CSCD，不是 SCI**，不满足第 0 节的硬性条件，只能作为国内毕业与职称认定口径下的独立路线。

### 7.5 中文路线的三点现实代价

1. **周期不占优**。《计算机学报》从投稿到见刊常超一年（录用后仍需排期）；《软件学报》《自动化学报》《通信学报》大致半年到一年。对比英文路线最快的 JMS（至录用约 122 天）与 IJCIP（初审 5 天），**若约束是时间，中文路线没有优势**。
2. **费用更高**。五大学报均收版面费，按页计，量级大致每篇两三千元至四五千元，高于 Elsevier 订阅模式的零费用。
3. **对负面读数的容忍度更低**。经验上中文刊审稿人对「如实报告不占优」的写法接受度低于 COSE/CAIE。这一点对 Paper04（C_max 全区间劣势）和 Paper02（A4/A6 低于仅标签消融）尤其关键：中文稿必须把「贡献是划界对象／是预算代价」写进摘要首句，而不是留在局限节。
